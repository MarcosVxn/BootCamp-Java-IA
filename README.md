# ☕ Bootcamp Java + IA — Itaú + DIO

Repositório dedicado aos meus estudos durante o **Bootcamp Java + IA**, realizado pelo **Itaú em parceria com a DIO**.

O bootcamp possui aproximadamente **45 horas de conteúdo** e aborda desde os fundamentos da linguagem Java até **Programação Orientada a Objetos, APIs REST, Spring Boot e Inteligência Artificial generativa**.

A jornada também conta com **desafios de código, desafios de projeto e atividades práticas**, buscando transformar os conteúdos estudados em aplicações e projetos para o portfólio.

---

## 🎯 Objetivo

Utilizar o bootcamp para desenvolver e aprofundar meus conhecimentos em **Java e desenvolvimento de software**, colocando os conteúdos estudados em prática por meio de exercícios, desafios e projetos.

Durante a jornada, meu foco é desenvolver principalmente:

- Raciocínio lógico e resolução de problemas;
- Programação em Java;
- Programação Orientada a Objetos;
- Desenvolvimento de APIs;
- Desenvolvimento Back-End;
- Spring Boot;
- Boas práticas de programação;
- Integração com bancos de dados;
- Integração de Inteligência Artificial em aplicações.
